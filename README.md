# Loan Officer Vault landing page

Static site, no build step. Deploy on Vercel: Framework Preset = Other, no build command, output directory = root.

Settings to edit at the bottom of index.html (SETTINGS block):
- CHECKOUT_URL: Gumroad product link
- LAUNCH_END: launch deadline (go-live date + 14 days)
- LAUNCH_PRICE / FULL_PRICE

Paste the Meta Pixel and Microsoft Clarity codes where marked in the <head>.
